# 칭찬 릴레이 크롬 확장

툴바 아이콘을 누르면 팝업에서 칭찬을 남기고 최신 칭찬을 볼 수 있어요. 저장은 배포된 칭찬 릴레이(https://praise-relay-jet.vercel.app)와 같은 API로 해서, 웹에서 남긴 칭찬과 확장에서 남긴 칭찬이 한곳에 모여요.

## 설치

1. 크롬 주소창에 `chrome://extensions`를 열어요.
2. 오른쪽 위 **개발자 모드**를 켜요.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `extension` 폴더를 골라요.
4. 주소창 오른쪽 퍼즐 아이콘에서 **칭찬 릴레이**를 고정하면 툴바에 주황 하트 아이콘이 생겨요.

코드를 고친 뒤에는 `chrome://extensions`에서 칭찬 릴레이의 새로고침 버튼을 눌러요.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `manifest.json` | 확장 이름, 아이콘, 팝업, API 주소 권한 |
| `popup.html`, `popup.css`, `popup.js` | 팝업 화면. 입력 검사는 웹 화면과 같아요 |
| `icons/` | 툴바와 확장 관리 화면에 보이는 아이콘 |

- 팝업은 열 때마다 새로 그려져서, 마지막으로 쓴 내 이름을 기억해 두었다가 채워 줘요.
- 배포 주소가 바뀌면 `manifest.json`의 `host_permissions`와 `popup.js`의 `API`를 함께 바꿔요.
